
# Corevia Commerce Platform

Plataforma de gestão comercial desenvolvida como projeto de portfólio Full Stack, com foco na construção de uma aplicação web para gerenciamento de processos comerciais.

O projeto utiliza Java e Spring Boot no backend, React no frontend e PostgreSQL como banco de dados.

O desenvolvimento será realizado de forma incremental, aplicando boas práticas de arquitetura, organização de código, integração entre sistemas e versionamento com Git.


## Tecnologias

### Backend
- Java 21
- Spring Boot
- Spring Data JPA
- Maven

### Banco de dados
- PostgreSQL

### Frontend (planejado)
- React
- JavaScript
- HTML e CSS

### Versionamento
- Git
- GitHub



## Funcionalidades planejadas

- Cadastro e gerenciamento de clientes
- Cadastro e gerenciamento de produtos
- Controle de estoque
- Registro e acompanhamento de pedidos
- Gestão de vendas
- Dashboard com indicadores comerciais
- Autenticação e controle de acesso
